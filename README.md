# 🎮 QuizMania — Quiz Interativo

## 📖 Sobre o projeto

O QuizMania é uma aplicação web interativa desenvolvida como projeto integrador da disciplina de Front-End.

O objetivo é proporcionar uma experiência divertida e educativa por meio de perguntas e respostas, utilizando HTML5, CSS3 e JavaScript.

## 🚀 Funcionalidades

- Interface colorida, moderna e responsiva.
- Botão para iniciar o desafio.
- Perguntas com alternativas de resposta.
- Temporizador para responder às questões.
- Sistema de pontuação.
- Exibição do resultado final.
- Possibilidade de jogar novamente.

## 💻 Tecnologias utilizadas

- **HTML5:** estrutura da aplicação.
- **CSS3:** estilização, cores e responsividade.
- **JavaScript:** interatividade, eventos, manipulação do DOM e funcionamento do quiz.

## ▶️ Como executar

1. Baixe os arquivos do repositório.
2. Abra a pasta do projeto no Visual Studio Code.
3. Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
4. Clique em "Começar desafio" para jogar.
